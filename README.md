# 班级座位表 v2.0.0

动态班级座位表系统，按周轮换，支持日历查看、V1/V2 两个版本、管理员编辑。

## 班级信息
- 48 名学生，5 组，共 26 桌（部分单人座）。
- 两套初始座位表：
  - **V1**：含鲁唐扬真，固定第 4 组第 1 排（不参与轮换）。
  - **V2**：不含鲁唐扬真（47 人，25 桌）。

## 核心模型
- **标准座位表**：所有组顶部对齐，轮换直接作用于此坐标。
- **实际座位表**：教室真实形状（第 1 组 2-4 排、第 2/3/4 组 1-6 排、第 5 组 2-6 排），为最终展示结果。第 1、5 组（及 V1 的第 4 组）在标准基础上整体下移一排。
- **轮换**：每周 组号 +1、排号 -1（向前移一排）；排号按「小组」（同桌初始所在组）的回绕上限取模。
- **假期**：国庆等假期（如 10/1–10/9）不换座；假期日子不计入换座周期，后续轮换相应顺延。
- **补位**：标准 → 实际时，落不进实际形状的「溢出桌」按「组号差 + 排号差」距离，以总距离最小（即平均值最小）填入空桌。
- **特殊规则**：熊晨伊/刘一诺、仝亚盈、杜卓航/樊霖洁、周加灵/隆竞瑶 四桌若落到第 5 组，与第 4 组同排（就近）交换，保证其不坐第 5 组。

## 功能
- 📅 日期选择器查看任意日期的座位表
- 🔀 切换 V1 / V2 初始座位表
- 🔐 管理员入口（密码保护），可修改起始日期与初始座位表
- 📱 响应式布局

## 运行
```bash
npx serve .
# 或直接双击 index.html 在浏览器打开
```

## 部署
- 挂在 Cloudflare Pages，连 GitHub 自动部署（push 即发布）。
- 后端存储：Pages Functions `/api/state`（GET 读 / PUT 写），KV 绑定变量名 `SEATS`。

## 跨设备同步
- 管理员在后台保存的「起始日期 / 初始座位表 V1 / V2 / 当前版本」会经 `/api/state` 写入 KV，其他设备打开页面时自动拉取，实现多设备共享。
- 前提：在 Cloudflare 后台创建 KV 命名空间（类型 Standard），并绑定到 Pages 项目，**变量名必须是 `SEATS`**（Settings → Functions → KV bindings → Add a resource binding → 选 KV namespace）。
- 未绑定 KV 时 `/api/state` 返回 500，前端会静默回退到本地 localStorage（各设备互不相通），不影响单机使用。
