# 班级座位表

动态班级座位表系统，支持按周轮换和日期查看。

## 班级信息
- 48 名学生，5 组 × 5 排，每桌 2 人
- 鲁唐扬真（1号）固定 4组1排，单人单座
- 王浩宇（2号）单人单座，不固定

## 换座规则
- 每周：组号 +1，排号 -1（到头循环）
- 每第 5 周：组号额外 +1（打破 5 周循环，循环延长至 25 周）
- 任意 10 周内，每人坐遍 1-5 排

## 功能
- 📅 日期选择器查看任意日期的座位表
- ⬅️➡️ 上/下周导航 + 键盘快捷键（← → T）
- ✏️ 点击姓名可编辑，自动保存到浏览器
- ⚙ 可配置学期开始日期
- 📱 响应式布局

## 运行
```bash
npx serve .
# 或直接双击 index.html 在浏览器打开
```
